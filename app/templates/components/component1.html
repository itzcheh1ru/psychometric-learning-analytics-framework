Component 01

Explainable Cognitive Offloading Risk Prediction

Develops an explainable machine learning model to predict cognitive-offloading risk based on GenAI usage behaviour, verification practices and learning strategies. Target-defining cognitive-offloading survey items are excluded from predictors to prevent data leakage.

Data Collection / Module Preparation

Methodology

Logistic Regression

Baseline interpretable classifier for binary risk classification.

Random Forest

Ensemble method capturing non-linear behavioural feature interactions.

XGBoost

Gradient-boosted trees for robust risk prediction performance.

SHAP Explainability

SHapley Additive exPlanations for global and individual prediction explanations.

Planned Analytical Outputs

  • Cognitive-offloading risk probability per participant
  • Risk classification (high / moderate / low)
  • Global feature importance (SHAP summary)
  • Individual SHAP waterfall / force plot explanations
  • Model comparison across classifiers
  • Calibration and evaluation metrics (accuracy, F1, ROC-AUC)
