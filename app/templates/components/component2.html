Psychometric Model Parameters

  • Latent Constructs: 5 (AT, PU, VB, AD, LC)
  • Total Survey Items: 19 Indicators
  • Response Scale: 5-point Likert (1=Strongly Disagree, 5=Strongly Agree)
  • Reverse-coded Item: AD4 → AD4_R = 6 − AD4 (Autonomy item)
  • Mediator: Verification Behaviour (VB)
  • Estimation Engine: semopy Covariance Modeling (lavaan-compatible)

Fornell-Larcker Discriminant Validity Matrix

Values on the diagonal (with asterisk) represent the square root of AVE (√AVE). Off-diagonal elements represent inter-construct correlations. Discriminant validity is satisfied when the diagonal value exceeds all corresponding off-diagonal values.

Heterotrait-Monotrait Ratio (HTMT) Matrix

HTMT values strictly below 0.85 confirm discriminant validity between constructs.
